# 🎲 Dice App

A simple app built using Swift and Xcode where users enter a number and the corresponding dice face is displayed.

## ✨ Features
- Enter a number to select a dice face.
- Display the corresponding dice face.
- Simple and user-friendly interface.

## 🛠️ Built With
- Swift
- Xcode
- SwiftUI / UIKit

## 🚀 Getting Started
1. Download or clone this repository.
2. Open the project in Xcode on a Mac.
3. Select an iOS Simulator.
4. Click **Run** to launch the app.
